What are the ground rules?
===

1. Heavily limit use of AI
- It is not fair to restrict AI usage, so we'll limit it
- Absolutely no code generation or copy-paste from AI
- Limit it to a more efficient search engine or an explanation tool

2. These programs need to be made without any pressure
- If you get the idea that one of these programs is going to be useful, then it is not for this repo
- All programs need to be fun/cool/creative in some way

3. Put your best/minimal effort into these
- Flex your creativity
- Ask yourself, "What would I find cool to put in this?"
- Minimal design time, just enough to get going

4. Document your process
- Do your best to actually learn from this
- Low pressure though

5. Stop if you are not having fun
- As soon as you feel like you need to be doing this, then stop
- Take a break
- Come back with zero pressure
